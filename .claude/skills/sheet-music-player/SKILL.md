# 五线谱 → 音频

流程：看谱 → 写成 `.score` 文本 → 检查小节时值 → 渲染 → 把音频发给用户 → 说明哪些地方没把握。

`scripts/render.py` 只依赖 numpy；有 ffmpeg 时输出 MP3，否则输出 WAV。默认只交付 MP3，不生成 MIDI；用户明确要 MIDI 时才加 `--midi`。

## 1. 先读全局信息

动手前先确定这几项，并在 `.score` 的文件头写下来：

- **调号**：数升降号。1♯=G，2♯=D，3♯=A，1♭=F，2♭=Bb，3♭=Eb。小调用 `Em`、`Dm` 这种写法，和关系大调等价。
- **拍号**：`4/4`，`C` 就是 4/4，`¢` 就是 2/2。
- **速度**：有 ♩=数字 就用它。只有文字时：Largo 50，Adagio 66，Andante 72，Moderato 96，Allegro 120。
- **每个谱表的谱号**：同一行谱中途可能换谱号。例如钢琴谱的右手开头常用低音谱号，几小节后才换成高音谱号。每一行谱都要重新确认。

谱号对照（容易读错，逐个核对）：
- 高音谱号：线 E4 G4 B4 D5 F5，间 F4 A4 C5 E5；下加一线 C4。
- 低音谱号：线 G2 B2 D3 F3 A3，间 A2 C3 E3 G3；上加一线 C4。

## 2. 写成 .score 文件

```
title: 曲名
tempo: 72          // 四分音符每分钟拍数
time: 4/4
key: G             // 调号里的升降号会自动加上，音符不用再写 #

[RH vel=0.30 pedal=0.35]     // 声部名随意；vel 是音量，pedal 是额外余音（秒）
r:.5 G3:.5 D4:.5 G3:.5 r:1 D4:.5 G3:.5 | r:1 D4:.5 ...
E4+G4+B4:1 ...               // 和弦用 + 连接

[LH vel=0.20 pedal=1.0]      // 用了延音踏板的声部，pedal 调大
E3:2 C3:.5 D3:.25 E3:.25~ E3:1 | ...
```

- **音符**写成 `音名八度:拍数`，以四分音符为 1 拍。全音符 4，二分 2，八分 .5，十六分 .25，附点八分 .75，三连音八分 1/3。
- **休止**写 `r:拍数`。
- **临时记号**：`#` 升，`b` 降，`n` 还原。它们在本小节内对同一音持续有效，和真实记谱规则一样。所以在 G 调里，`F4` 是 F#4，`Fn4` 是 F 本音。
- **连音线**：在前一个音后面加 `~`，下一个同音高的音就并进去。跨小节也可以。
- **小节分隔**：一行写一个小节，或者在一行里用 `|` 隔开。
- **注释**用 `//`，不能用 `#`，因为 `#` 是升号。建议每段前面标上小节号和歌词，方便以后对照修改。
- **声部**：一行谱表一个声部。如果一个谱表上有符干朝上、朝下两条旋律，就拆成两个声部，每个声部每小节都要凑满拍数。
- **反复记号**（`𝄆 𝄇`、D.C.、跳房子）：照实际演奏顺序把小节展开重写。
- 可以参考示例 `examples/qingtian.score`。

## 3. 检查，然后渲染

```bash
python3 scripts/render.py song.score --check              # 列出拍数不对的小节，有问题时退出码为 1
python3 scripts/render.py song.score -o <输出目录>/song    # 只生成 song.mp3
python3 scripts/render.py song.score --bars 9-12          # 只渲染这几小节，用来核对片段
python3 scripts/render.py song.score --tempo 60           # 临时改速度
```

`--check` 必须全部通过才能渲染。拍数不对几乎一定是读错了时值或漏了音，回去对照原图重看那一小节，不要随手补个休止符凑数。

## 4. 交付

- 用 SendUserFile 发 MP3，`display: "render"`，用户可以直接播放。只发 MP3，不要附带 MIDI 或其他文件。
- 把 `.score` 文件保存在用户看得到的地方，告诉用户路径。以后改某一小节就是改一行文本。
- 说清楚：转了第几到第几小节；速度和调；哪些小节是看不清、靠估计的。说明时用小节号加歌词定位。
- 你听不到音频。只说“已生成”，不要说“听起来正确”。
- 音色是程序合成的简易钢琴，不是真钢琴录音，要告诉用户。

## 常见错误

- 漏看谱号变化，导致整段音高差一个八度以上。
- 忘了调号，导致某些音没升没降。用了 `key:` 就不要在音符上再写一遍 #。
- 读错附点、十六分和连音线，导致拍数不对。`--check` 能查出这一类。
- 把指法数字（1–5）当成音符或三连音标记。
- 只看第一页。多页谱要问用户是否全部转换，或者按页逐段转。
